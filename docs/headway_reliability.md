# Cancellation And Headway Reliability

Cancellation facts require an explicit GTFS-Realtime cancellation relationship.
The absence of an update is a coverage gap, never cancellation evidence.

Observed headways retain their evidence method. Excess waiting time is calculated
only for eligible frequent-service groups with enough observations and a planned
baseline; ineligible groups publish an exclusion state rather than a misleading
number. Route and network summaries expose their component metrics and confidence
instead of an opaque universal score.
